# Northstar Analytics — SaaS dashboard demo

A self-contained portfolio demonstration. Open `index.html` in any modern browser, or deploy this directory to Vercel as a static site.

## Features
- Responsive dark dashboard and sidebar navigation
- Interactive date-range and customer-segment filters
- SVG trend chart with hover details and plan comparison bars
- Customer directory with live search and status filters
- Revenue metrics, transactions, reporting and insights
- Currency display preference, compact tables and reset controls
- Local CSV export

All data is fictional. There is no backend, authentication, tracking, network request, or live payment integration.

To add to an existing portfolio, place the directory at `/dashboard/` and link to `/dashboard/index.html`.
